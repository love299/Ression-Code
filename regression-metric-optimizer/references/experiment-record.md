# 实验记录规范

每次会话建立独立目录，名称含时间与唯一标识，避免覆盖已有结果。使用 JSON/JSONL 保存机器可读原始记录，并生成 Markdown 或 CSV 汇总；缺失值写 null 并注明原因，不能填充伪造指标。记录先落盘再切换最优版本；中断恢复时核对状态、文件哈希和产物完整性。

## 会话协议

记录 session_id、项目原路径、初始 HEAD（若有）、原始工作区状态、代码快照/哈希、相关未跟踪文件、原始已暂存/未暂存 Diff 路径、数据版本/哈希、划分 ID、种子、目标与聚合方法、依赖和硬件、训练命令、超时、预算、阈值、测试集未访问声明及实际例外。

分开记录 split_seed、model_seeds 和实际 split_manifest。记录拟合次数上限与消耗、确认批次规则、相对 B00 的 Pearson 下限，以及基线是否有效。修复运行用独立 repair_id，记录改动、重跑及开销，不计为性能提升；总拟合开销仍计入预算。

记录基线 B00；每个候选使用 E01 至 E08，额外候选仅在获得预算授权后分配。一次候选的各重复使用 run_id，不重复使用已失败的 experiment_id。对训练/评估失败的运行也保存命令、退出码和日志。

## 每个候选必填字段

- 标识：experiment_id、parent_best_id、时间、状态（planned/running/accepted/rejected/failed/interrupted）、是否保留修改。
- 假设：优化思路、证据、唯一因素、旧值、新值、修改文件与代码位置。
- 来源：父版本与候选代码哈希、数据/划分/协议 ID、相对父版本的 Git Diff、相对基线的累计 Git Diff、代码副本路径。
- 执行：命令、工作目录、种子/折、环境、开始结束时间、耗时、退出码、日志、检查点、预测及匹配样本 ID 文件路径。
- 指标：修改前后 R²、Pearson、RMSE、MAE，各配对运行的原始数值、均值/标准差、差值。修改前指当前最优，另保留初始 B00 便于累计比较。
- 校验：预测键唯一性、样本集合及标签一致性、代码/配置/检查点与预测的来源对应、各指标定义与聚合规则。记录相对 B00 的累计 Pearson 差值、MAE/RMSE 权衡和用户约束判定。
- 决策：接受阈值、每项判据结果、实验结论、失败或拒绝原因、回滚是否完成、决策后的 best_id、已用候选预算和训练运行数。

汇总表使用如下列，RMSE/MAE 也必须明确展示前后数值：

| 实验 | 父最优 | 修改位置/唯一因素 | R² 前→后 | Pearson 前→后 | RMSE 前→后 | MAE 前→后 | 结论 | 保留 | 决策后最优 |
|---|---|---|---|---|---|---|---|---|---|

汇总表是账本的视图，不能代替运行级原始记录。失败实验指标可缺失，但异常、状态和回滚结果不可缺失。不要删除失败候选及其补丁、日志来美化结果。

状态变化以追加事件保存，保留 planned → running → 最终决策的时间与依据，不重写失败历史。最优清单包含 best_id、protocol_id、代码哈希、指标文件哈希、完整运行 ID 和决策事件 ID；先完成决策记录再原子更新清单。中断时未落盘完成的候选只能记为 interrupted，不得据未确认日志晋升。

## 最终产物索引

索引应包含协议、完整账本、汇总表、B00 与最佳版本代码目录、所有实验 Diff/日志/预测、最佳版本复现命令和接受链。只把通过全部判据的候选标为最优；无通过候选则 best_id 为 B00。
